# my-studio-starter

Starter folder for the BGU Claude Code evening workshop (Intro to Information Systems).

**Download:** green **Code** button → **Download ZIP**, or this direct link:
https://github.com/dcodish/my-studio-starter/archive/refs/heads/main.zip

Extract it, then in the Claude app open the **Code** tab and pick the folder
`my-studio-starter-main`. No Git needed.

| File | What it is |
| --- | --- |
| `IDEA.md` | Your brief: what you build, for whom, the 3 must-haves. Fill it in round 1. |
| `IDEAS.md` | The idea menu. |
| `PROMPTS.md` | The prompt for each round. |
| `BONUS.md` | Ideas for the open work hour (21:00–22:00). |
| `CLAUDE.md` | Project rules Claude reads at the start of every chat. |
